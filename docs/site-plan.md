# reworkstudio.net 홈페이지 기획 (2026-11-03)

## 왜 바꾸나
- 9/17 기획: 홈페이지는 방법론·사례·진단 기준을 쌓는 **원본 자산 채널**, 네이버 블로그는 각색한 배포 채널. 모든 콘텐츠의 종착지는 **무료 계정 분석 신청(/lead)**.
- 9/20 배포본은 `/portfolio`(상품설명서)와 `/lead`(신청) 두 장뿐. `/`는 `/portfolio`로 임시 이동.
- 빠진 것: 홈페이지 블로그(인사이트), 사이트 메뉴, 검색 기본 설정(robots·sitemap·canonical·OG·구조화 데이터), www/apex 중복 주소 정리.

## 사이트 구조 (v3, 2026-11-03 전면 개편)
원칙: 한 페이지에는 한 가지 이야기만. 홈은 각 페이지의 예고편이고, 자세한 내용은 해당 페이지에만 둔다.

| 메뉴 | 주소 | 이 페이지가 답하는 질문 | 들어가는 것 |
|---|---|---|---|
| 홈 | / | 여기는 뭐 하는 곳이야? | 한 줄 소개, 이런 분께 맞아요, 사례·서비스·회사·블로그 요약(각각 더 보기), 무료 분석 |
| 회사 소개 | /about | 누가 하는 거야? | 저희가 믿는 것, 하는 일 3가지, 대표 소개, 함께한 브랜드, 연락처 |
| 서비스 | /services | 뭘, 얼마에, 어떻게 해 줘? | 진행 순서 5단계, 가격 3가지(상세), 추가 상품, 자주 묻는 질문 |
| 포트폴리오 | /portfolio | 진짜 결과가 있어? | 성과 숫자 4개, 4개 계정 × 대표 콘텐츠 3편 |
| 블로그 | /insights | (검색으로 들어오는 사람) | 글 목록, 글 |
| 무료 계정 분석 | /lead | 어떻게 시작해? | 신청서 |

- 예전 /portfolio(상품설명서) 주소는 새 포트폴리오 페이지로 그대로 이어진다.
- 상단 메뉴: 회사 소개 · 서비스 · 포트폴리오 · 블로그 + [무료 계정 분석]. 모바일은 햄버거 메뉴.
- 데이터(가격, 진행 순서, 브랜드, FAQ)는 scripts/build.mjs 위쪽 "site data"에서 한 번만 고친다.

## 인사이트 운영
- 카테고리: 퍼스널 브랜딩 / 스토리 브랜딩 / 문의 동선 (필요 시 확장)
- 글 양식: `rework-content-writing-rules.md` 그대로 (훅 → 3줄 요약 → 근거 → 리워크 해석 → 업종 적용 → 실행 3가지 → 무료 분석 CTA) + FAQ + 출처 목록 + 저자 박스
- 네이버 블로그 글을 그대로 복사하지 않는다 (유사문서 위험). 같은 주제라도 홈페이지용으로 새로 쓴다.
- 글 추가 방법: `content/insights/{slug}.md` 작성 → `node scripts/build.mjs` → 커밋·푸시

## 검색(SEO·GEO) 기본
- 대표 주소: `https://reworkstudio.net` (www → apex 301)
- 모든 페이지 canonical, description, OG/Twitter 카드
- 구조화 데이터: 홈 ProfessionalService + Person + FAQPage, 글 BlogPosting + BreadcrumbList + FAQPage
- `robots.txt`, `sitemap.xml`, `/insights/feed.xml`(RSS)
- 배포 후 할 일(관리자 권한 필요): Google Search Console·네이버 서치어드바이저 소유 확인, 사이트맵 제출

## 글쓰기 규칙: 5초 규칙 (2026-11-03 추가)
대표님(필라테스 원장, 상담사)이 처음 읽고 5초 안에 이해 못 하면 고친다.
- 어려운 말 금지: 언어화, 퍼널, 동선, 전환, 내러티브, 서사, 구조화, 시그니처, end-to-end, 프로파일. 꼭 필요하면 쉬운 말 뒤 괄호로 한 번만.
- 회사 방식 표현: 이야기 듣기 → 할 말 정리 → 콘텐츠 만들기 → 문의로 연결
- 한 섹션 = 제목 한 줄 + 짧은 설명 한 줄. 문장은 50자 안팎.
- 메뉴·버튼은 한국어 일상어 (블로그, 서비스, 무료 계정 분석 받기)
- `node scripts/build.mjs`를 돌리면 어려운 말이 남아 있을 때 경고가 뜬다.
